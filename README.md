# 📚 BookVerse

BookVerse is a modern and responsive **book discovery web application** built using **React + Vite**.  
It uses the **Open Library API** to fetch and display real-time book data, allowing users to search and explore books easily.

---

## 🚀 Features

- 🔍 Search books by title, author, or subject
- 📖 View detailed book information
- 🌐 Real-time data from Open Library API
- ⚡ Fast performance with Vite
- 📱 Fully responsive design
- 🧩 Component-based React architecture

---

## 🧠 Tech Stack

- **Frontend:** React + Vite
- **Styling:** CSS / Tailwind CSS
- **API:** Open Library Public API
- **State Management:** React Hooks (`useState`, `useEffect`)
